03 / 经典电路拓扑

电源经 RFC 向漏极馈电；Q1 周期性接地；Csh 是漏极对地总电容；输出 Ls、Cs、R 串联。这里的 R 是等效射频有功负载，不代表真实线圈直流电阻。

04 / 使用前请先分清“串联谐振”与“E 类最佳负载条件”

ω = 2πf
R = 0.5768 · VDD² / Pout
Csh,total = 0.1836 / (ω R)
ωLs − 1/(ωCs) = 1.1525 R
Qc = 1/(ωCsR) ; Qs = ωLs/R = Qc + 1.1525
Ls = (Qc + 1.1525)R/ω ; Cs = 1/(ωQcR)
I0 ≈ Pout/VDD [仅理想 η=100%]
LRFC ≳ VDD/(2 f I0 r) [粗略纹波估算；r = ΔIpp/I0]

输出网络在开关频率 f 下需要一定的正感性电抗，因此 Ls 和 Cs 的自然串联谐振频率 f0 一般低于开关频率。若直接令 f0=f，网络净电抗为 0，就不满足这组理想经典参数。RFC 纹波公式只把半周电感受压粗略视为 VDD，真实开关节点电压不是方波，有限馈电电感必须重新仿真验证，不能保证给定百分比。

设计假设：单端 50% 占空比、负载支路近似单频正弦、理想 MOSFET、无元件损耗且 RFC 足够大。真实器件还涉及 Coss(Vds)、开关时间、Qg、线圈 Q、ESR、PCB 寄生与有载阻抗变化。理想 Vds,max≈3.562VDD 是标称匹配点的估算，实际失配/瞬态可能明显更高，要按仿真和实测选 MOSFET 耐压。

导出的 LTspice .cir 使用无内建 Coss 的理想开关，因此网表中的 Cshunt 填入总 Csh；将来替换成真实 MOSFET 模型后，必须按器件 Coss 重调外加电容，以免重复计入。该网表用于观察稳态 V(d)、I(Lseries)、P(Rload)。实际做硬件前，务必替换 MOSFET、Coss、ESR、线圈和有限 RFC 模型，验证开通前 Vds≈0 且斜率≈0，检查开关尖峰和电容损耗。
